所以，DNS 就是运营商吗？阿里和腾讯又怎么选？

不是。DNS 是一套分工协作的系统，相关程序运行在联网的服务器上。代查服务可能来自运营商，也可能来自其他服务商；电脑或浏览器的设置决定先问谁。

假设网页放腾讯、权威 DNS 放阿里：站长在阿里写地址记录，经注册商把域名的负责服务器登记到上级。代查者按登记找到阿里的权威 DNS，再取得腾讯网站服务器的地址。查地址与提供网页，是两项不同工作。

如果网站搬家，改哪样东西？

先让新服务器能提供网页，再把对应地址记录更新成新地址。网站名可以不变；若 DNS 托管方没换，不必仅因网站搬家而更换上级 NS 委派。

但大家不会同时切换：之前查到的旧地址可能仍在有效缓存中。刷新网页也不保证立刻重新查询到新地址。

这个小剧场省略了什么？

小鸟代表读者的期待、误会与反应，不是解析器。电脑、便签与花都是教学图形，便签并非真实报文，花代表图片内容而非实物传送。example.com 与 203.0.113.10 是教学示例，不代表它们实际对应。

主线只画无相关缓存、直接 A 记录返回单个 IPv4 地址的成功查询；其他情况可能涉及 IPv6、多个地址、别名、CDN、转发、加密 DNS 或失败。同一地址可以提供多个网站，所以浏览器连接时仍需要网站名。取网页与图片可能有多次请求，本图合并表示。

NS 值是服务器名字。转介有时附带 glue 地址，有时需要另行解析服务器名；本页没有把这些额外往返画出来。.com 与 .cn 是顶层分类，不是物理地点，也不各自只有一台机器。
