# chengfeng-jiedu

This is the installer package for `chengfeng-jiedu`（成峰解读）.

Install it with:

```sh
npx -y github:Agentchengfeng/chengfeng-jiedu install
```

The installed skill explains an unfamiliar concept from one concrete example, step by step, and turns the explanation into a picture-first HTML page you scroll through.
