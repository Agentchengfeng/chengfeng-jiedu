# 小鸟风格与 HTML 实现

本文件负责样式、素材和页面技术要求；解释逻辑与内容验收以 SKILL.md 为准。

## 参考样张

采用默认小鸟风格时，读取 [《我花呢？》参考模板](../assets/dns-bird-comic-reference.html)，复用角色资产和图形语言，不照搬 DNS 文案、花、四格数量或后半段回溯。用户指定其他风格时不强制读取该模板。

新稿另存到任务目录，不覆盖样张。替换标题、文案、图内标签、无障碍描述、来源和示例链接；`data-ledger` 按实际账本更新，无需追溯标记时删除，不保留错误的示例节点。

## 视觉语言

| 部分 | 默认选择 |
|---|---|
| 纸面与轮廓 | 纸白 `#faf9f5`、白色画格、轮廓与正文 `#252525`、次级文字 `#66645f`。 |
| 功能色 | 黄 `#f7c659`、浅黄 `#fff0c6` 表示线索与结果；橙 `#d88621` 表示方向或强调。粉色花只是样张内容色。 |
| 图形 | 清晰轮廓、平涂道具、少量纸条倾斜和硬边阴影。框线用于分隔事件，不把段落装进卡片冒充图解。 |
| 字体 | PingFang SC / Microsoft YaHei / Arial；编号等按需用等宽字。标题约 20–23px、短注约 13–16px 为起点，按实际尺寸保证可读，不缩字塞内容。 |
| 容器 | 参考最大宽度约 980px；桌面可并排画关系，窄屏按阅读逻辑重排。参数是起点，不是固定布局合同。 |

## 小鸟与表情

- 小鸟承担读者的期待、疑问、误会和释然，不自动代表系统中的所有角色；没有具体作用时不出场，不要求每格搞笑。
- 表情围绕具体预期差使用，既不依赖读者熟悉流行梗，也不凭空替用户编造已证实的想法。现成素材需语义适配且使用条件允许。
- 静态角色复用模板内联 `symbol`，保持黑鸟身体、白眼和橙黄嘴脚的比例。`bird-curious/confused/happy` 主要通过视线和对白区分语境，不代表丰富动作已实现。只有需要新增小鸟动作时才使用可用的 `bird-svg-motion`；资产缺失要说明。
- 模板含私人小鸟 IP；个人使用不等于公共分发授权。公开分享或打包该素材前确认授权，不整包复制私人素材库。

## 密度与交互

- 内容自然纵向滚动，高度随内容决定。不默认分页、滚动吸附、整屏卡片或用固定高度与大面积空白制造稀疏感。
- “太密”先分清原因：同时引入过多未知关系时拆步并接清；只是字号、折行、间距不佳时调整布局。新增节拍应减少理解跳步，不只增加滚动距离。
- 主线无需点击、悬停或等待动画即可理解。动效仅作辅助，提供静态结果、无脚本回退并尊重减少动态效果偏好；用户明确要求的互动演示可以额外操作。
- 优先 HTML/CSS/SVG；动画、试听、A/B 或其他交互只在它们能直接演示当前难点时加入，位图用于确有必要的素材。

## 页面技术检查

默认仅用 **Codex 内置浏览器**打开、预览、交互检查和截图；其他浏览器须用户明确指定。不可用或访问被阻止时报告限制，不自行换浏览器或绕过限制，也不把源码校验写成实际视觉通过。

实际检查桌面与窄屏：中文和标签可读，SVG 与箭头关系清楚，内容不截断、不横向溢出；ID、内部锚点和资源链接有效；必要交互与静态回退可用。不用技术通过替代 SKILL.md 的内容验收。
